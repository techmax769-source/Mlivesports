# MLiveSports ⚽

A production-ready football sports website built with Next.js 14, TypeScript, and Tailwind CSS. Features live scores, match highlights, leagues, standings, betting tips, and football news.

## Features

- 🏆 **Live Football Scores** with auto-refresh
- 🔍 **Global Search** for players, teams, venues, and matches
- 📊 **League Standings** (EPL, La Liga, Bundesliga, Serie A, Ligue 1, UCL, Euros, FIFA)
- 💡 **Betting Tips** with intelligent caching
- 📰 **Football News** with card-based layout
- 📱 **Fully Responsive** mobile-first design
- 🛡 **Error Handling** with graceful fallbacks
- ⚡ **Performance Optimized** for Vercel

## Tech Stack

- **Next.js 14** with App Router
- **TypeScript** (strict mode)
- **Tailwind CSS** for styling
- **SWR** for data fetching and caching
- **Axios** for API calls
- **Lucide React** for icons

## API Integration

The website consumes a custom REST API hosted on Vercel with endpoints for:
- Live scores and highlights
- League data and standings
- Player and team search
- Betting tips and news
